# Archived Initial Page OCR

The Markdown files in this directory are the original one-file-per-PDF-page
outputs from the vision OCR pass. They are archived in place so existing
provenance links remain valid.

Do not use these files as the canonical text source. The current best OCR text
is `../godfrey_isgur_1985_vision_ocr.md`, which contains manual improvements
and higher-quality table transcriptions that are not reflected here.

The page split was not a good semantic boundary for this paper. Many important
objects span the full page or interrupt the two-column flow, so fixed page and
column OCR crops can be incomplete or misleading.
