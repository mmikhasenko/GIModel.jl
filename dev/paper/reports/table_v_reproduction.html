Table V Strong-Decay Reproduction ​

Generated by julia GIPaper/checks/reproduce_table_v.jl. Every canonical table_v_strong_decays.csv amplitude row is accounted for. Rows with a pure-state operator are computed with the row-oriented decay_amplitude API. Each amplitude factorizes as c * X(qbar) * spatial_overlap (matrix element x numerical overlap). The coefficient c (Appendix B) and the class algebra X (Table IV) are the paper's; A, S0, the spatial overlap and the decay momentum are derived here.

  • A = 1.644 from rho -> pi pi = +12.4 (q = 362 MeV)

  • S0 = 3.291 from B -> [omega pi]_S = -11 (q = 347 MeV), leading-S0 convention

  • Kinematics use the shared PDG 2026 mass registry, including stated charge averages.

  • NaN means a required experimental assignment is unavailable; no GI/model mass fallback is used.

  • The paper's two amplitude calibration anchors are retained and evaluated at modern kinematics.

  • Fixed beta and mixing angles retain the GI operator prescription. Broad effective daughters are deferred.
