# Replaceable Visual Theme: Cartoon Llamas And Orcas

This theme is intentionally separate from the scientific poster content. Replace
this file to change visual direction without rewriting the six poster briefs.

## Concept

Use a friendly scientific expedition aesthetic: llamas carry the layered model
components through mountainous parameter terrain, while orcas navigate the deep
water of quantum operators. The style should be playful but precise: cartoon
characters help wayfinding, while the equations, numbers, and diagrams remain
clean and serious.

## Visual Metaphors

- Llamas represent "load-bearing workflow":
  - carrying Table II parameter packs;
  - walking along the radial grid;
  - stacking layers of the model;
  - holding checklists for tests and provenance.
- Orcas represent "deep operator physics":
  - diving through smeared potentials;
  - swimming around momentum-space sandwiches;
  - surfacing with fine-structure splittings;
  - circling the final residual scorecard.
- Mountains represent the paper-to-code translation challenge.
- Ocean layers represent operator layers below the visible spectrum.
- Bridges represent code paths that connect paper formulas to numerical reports.

## Style

- Cartoon editorial infographic, not children's-book clutter.
- Rounded hand-drawn accents are okay, but keep tables and equations crisp.
- Use thick clean outlines for mascots.
- Use simple facial expressions:
  - curious llama for "input/provenance";
  - focused llama for "solver";
  - diving orca for "operator layer";
  - celebratory but restrained pair for "results".
- Avoid visual noise around formulas. Equations should appear on clean panels or
  ribbons, with mascots beside them rather than behind them.

## Palette

Use this as a starting palette:

| role | color | hex |
|---|---|---|

| central Hamiltonian | deep teal | `#126B6F` |

Keep the scientific layer colors consistent across all six posters.

## Typography

- Poster title: friendly slab or rounded grotesk, bold.
- Section labels: compact sans-serif, all title case.
- Equations and code labels: monospaced or math serif.
- Captions: short, high-contrast, no tiny text.

## Layout Motifs

- Use a small "expedition map" ribbon at the bottom of every poster showing
  position: `1 Workflow -> 2 Inputs -> 3 Central -> 4 Smearing -> 5 Spin -> 6 Results`.
- Use layer badges:
  - Paper object
  - Code object
  - Diagnostic object
- Use mascot placement as navigational markers:
  - llama in upper-left for setup/input;
  - orca in lower-right for operator/result;
  - both together only on Poster 1 and Poster 6.

## Do Not Do

- Do not let mascots obscure equations, tables, or code paths.
- Do not make every panel a joke. The model explanation is the point.
- Do not use realistic animal photography in this theme.
- Do not use a one-color blue ocean palette. Keep the layer colors distinct.
- Do not overuse speech bubbles. One small bubble per poster is enough.
